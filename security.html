Small site. Clear boundaries.

This portfolio is a static website. There are no visitor accounts, submission forms, advertising scripts, or third-party analytics. The core content and contact links work without JavaScript.

How the page is delivered

Fonts, images, styles, and scripts are served from this site. Browser policies restrict executable scripts and styles to this origin, disable inline handlers and framing, and block application network connections. HTTPS and HSTS protect delivery.

Deployment uses an explicit list of public assets. Repository instructions, local notes, test tools, and deployment internals are excluded from website hosting.

Report a vulnerability

Email kaupo@2km.ee with the affected URL, reproduction steps, and likely impact. Please avoid sending credentials or personal data.

The machine-readable contact is security.txt. The information on this page describes implemented controls; it is not a certification or a promise that vulnerabilities cannot exist.
